<h3 id="Question-1:-Setup-and-modeling-choices">Question 1: Setup and modeling choices¶</h3><p>Country. I used Japan, which appears as a single row in the file. t = 0 is the first date in the file (1/22/20), because Japan already had cases on that date.</p> <p>Definition of Y_t. The file contains cumulative confirmed cases (a running total). I defined Y_t as daily new cases, the day-to-day difference of the cumulative counts (np.diff) rather than the cumulative counts (Y = cumulative). I chose this because:</p>
  1. Question 4 asks whether cases go "up or down." Japan's running total never decreases (0 of 1,142 days), and new cases were reported on all but 10 days, so a "went up" indicator built from the running total would be 1 on almost every day. Daily counts move in both directions.
  2. With the running total, the five lagged predictors are nearly identical (pairwise correlations above 0.9998). With daily counts they are still highly correlated (at least 0.89), but less so, so individual coefficients should be interpreted cautiously.
<p>Indexing. Because np.diff takes the change from one day to the next, the first daily value is the change from day 0 to day 1, so the series Y_t starts at t = 1 (1,142 daily values from 1,143 days of cumulative counts). The regression then uses t = 6 through t = 1142 (1,137 rows), because the first five daily values are needed as lags.</p> <p>A comparison using the cumulative counts is in the code cell just above the report table.</p>

<h3 id="Question-1:-Results-and-interpretation">Question 1: Results and interpretation¶</h3><p>I modeled Japan's daily new cases (Y_t) as a linear function of the previous five days: Y_t = α₀ + β₁Y_{t-1} + β₂Y_{t-2} + β₃Y_{t-3} + β₄Y_{t-4} + β₅Y_{t-5} + ε_t. The model used 1,137 days, and R² = 0.917.</p> <p>Interpretation of each coefficient. Each coefficient is the expected change in today's new cases for one additional new case on that earlier day, holding the other four lags constant.</p>
  • Y_{t-1} (0.829): Yesterday's count (day t−1) has by far the largest weight. 1,000 more cases on day t−1 goes with about 829 more cases on day t, with the other lags unchanged.
  • Y_{t-2} (-0.247): Negative, even though the number of cases two days ago is strongly positively related to today's number on its own. Alone, its coefficient is +0.910; with Y_{t-1} added it is +0.060; with all five lags it is -0.247. A coefficient here measures what a lag adds beyond the others, and the lags overlap heavily, so this should not be read as "more cases two days ago lowers cases today."
  • Y_{t-3} (0.274) and Y_{t-5} (0.158): Positive, with intervals that exclude zero, so these days still add information once the other lags are included.
  • Y_{t-4} (-0.039): Its interval includes zero (p = 0.313), so the data cannot distinguish it from no contribution.
  • Intercept (719): The predicted count if all five previous days were zero. It is not distinguishable from zero (p = 0.157) and is not a meaningful quantity on its own.
<p>Comparison with cumulative counts. Using the cumulative counts as Y gives Y_{t-1} = 1.8425 and Y_{t-2} = -1.0523, with R² near 1 and lag correlations above 0.9998. The coefficients are nearly uninterpretable individually, which supports using daily new cases.</p> <p>Caution. The lagged predictors are highly correlated, so individual coefficients should be read with care, and these are associations used for prediction, not causal effects.</p> <p>Overall. The five coefficients sum to 0.976, so a one-case increase across all five previous days goes with an expected increase of about 0.98 cases today. The recent past predicts the present almost one-for-one, with yesterday's count (day t−1) carrying most of the weight.</p>

<h3 id="Question-2:-Results-and-interpretation">Question 2: Results and interpretation¶</h3><p>Prediction error = actual − predicted new cases. Part (a) fits the model on all of Japan and applies it to the same days; part (b) fits on the first half (days 6 to 573) and applies it to the second half (days 574 to 1142).</p> <p>MSE for (a) is about 2.16 × 10⁸ and for (b) about 5.28 × 10⁸. Part (a) is optimistic because the model is tested on the same days it was fit on. Part (b) is tested on days the model was not fit on, but the two halves also differ greatly in level: average daily new cases were about 2,086 in the first half and about 56,477 in the second, and the first-half maximum was 20,496 against 260,999 in the second half. The model fit on the first half therefore has to predict much larger counts than it was trained on. On the same second-half days, the model fit on all of Japan has an MSE of about 4.30 × 10⁸, so much of the gap between (a) and (b) comes from (a) also averaging in the quiet first half.</p>

<h3 id="Question-4:-Results-and-interpretation">Question 4: Results and interpretation¶</h3><p>Report. The model used 1,136 days (t = 7 to 1142). Cases went up on 46.9% of days. The full table of coefficients, standard errors, p-values, and odds ratios is printed in the cell above (report_logit).</p> <p>How to read the coefficients. Each coefficient is the change in the log-odds that cases go up today when that earlier day was an increase (Z = 1) rather than not, holding the other four days fixed. Exponentiating gives an odds ratio: the factor by which the odds of an increase today are multiplied.</p>
  • Intercept (coefficient 0.68, odds ratio 1.98): The odds of an increase are about 1.98 to 1 after five straight days without an increase, which is a probability of about 0.66.
  • Z_{t-1} (coefficient 0.38, odds ratio 1.46): The only positive coefficient. If cases went up yesterday, the odds of an increase today are about 46% higher.
  • Z_{t-2} (−0.83, odds ratio 0.44) and Z_{t-5} (−0.69, odds ratio 0.50): The strongest effects, and both negative. An increase two days ago cuts the odds of an increase today by about 56%, and an increase five days ago cuts them by about 50%.
  • Z_{t-3} (−0.32, odds ratio 0.73) and Z_{t-4} (−0.26, odds ratio 0.77): Smaller negative effects. The interval for Z_{t-4} comes close to 1 (upper limit 0.985), so that one is the least certain.
<p>Overall pattern. Only yesterday's increase raises the odds of an increase today, while increases on each of the previous four days lower them. In predicted probabilities: if only yesterday was up, the chance of an increase today is about 0.74; if all five previous days were up, it falls to about 0.26. After a run of increases, a decrease becomes more likely.</p> <p>Caution. The model is a weak predictor (pseudo R² of 0.056, shown in the model summary), and it uses only five days, so it cannot capture longer cycles such as a weekly pattern. These coefficients are associations, not causal effects.</p>
